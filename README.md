# Art Progress Hub

Create a polished, premium web application called "ART//PROGRESS" — a personal art progress tracker and digital artist dashboard.

The app is designed for one artist who wants to track their drawing practice, build a portfolio of their studies, monitor individual art skills, record mistakes and insights, and visually see their improvement over months and years.

IMPORTANT:

This should NOT look like a generic productivity app, Notion clone, admin dashboard, or corporate SaaS.

It should feel like a beautiful personal digital art studio / creative laboratory from the near future.

VISUAL DIRECTION:

- Dark premium interface

- Elegant futuristic aesthetic

- Artistic but professional

- Deep charcoal / almost-black background

- Subtle glassmorphism

- Soft gradients and restrained glow effects

- Beautiful typography

- Lots of negative space

- Large artwork thumbnails

- Thin elegant borders

- Subtle shadows

- Smooth hover animations

- Small micro-interactions

- Avoid excessive neon and cyberpunk clichés

- Avoid making everything glow

- The interface should feel expensive, calm and sophisticated

- Think "digital artist's private studio in 2035", not "gaming RGB dashboard"

Use a refined dark palette with neutral charcoal tones and one tasteful accent color.

The accent should be used sparingly for progress indicators, selected navigation items, charts and important actions.

ACHIEVEMENTS:

Add a compact achievements section with tasteful badges.

Do NOT make this look childish or like a mobile game.

Keep achievements elegant and minimal.

UX:

The dashboard should be responsive.

Desktop-first, but also work well on tablet.

Use smooth transitions between pages.

Buttons should have subtle hover states.

Cards should have slight elevation / border changes on hover.

Use Lucide icons.

Use modern React + TypeScript components.

Use Tailwind CSS.

Use a clean component architecture.

IMPORTANT DESIGN PRINCIPLE:

The artwork itself should always be the visual star.

The UI must frame and support the art rather than compete with it.

Make the application feel motivating and emotionally satisfying to open every day.

I want the result to look like a real premium product that could actually be released, not an AI-generated template.
